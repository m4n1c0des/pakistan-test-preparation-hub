# Question bank

`questions.json` is the canonical structured bank. `question-index.csv` is a searchable index; `answer-key.md` is a compact key.

- v1.0.0: 80 original practice MCQs.
- v2.0.0: 98 additional original practice MCQs; 178 total.
- v3.0.0: 322 additional original practice MCQs; 500 total.
- The 98 v2 and 322 v3 additions passed structural checks but remain pending independent human subject-matter review.
- v3 questions include short Roman Urdu learning notes; they are not full translations of every English explanation.
- Exam tags mean topic alignment, not that an item appeared in a real exam.
- Difficulty labels are editorial estimates, not calibrated statistics.
- The bank is not yet large enough to generate full, exam-weighted papers for every listed category.

Run `python scripts/validate_question_bank.py` from the repository root.
