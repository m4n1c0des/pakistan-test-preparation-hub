# Central Superior Services (CSS) Competitive Examination

**Authority:** Federal Public Service Commission (FPSC)  
**CSS notices and stages:** https://www.fpsc.gov.pk/Jobs?section=CSS  
**Syllabuses:** https://fpsc.gov.pk/Syllabuses?section=GR+Syllabus  
**Checked:** 2026-11-24

## Assessment stages

CSS is not simply an MCQ test. FPSC publishes a screening MPT, written competitive examination, psychological assessment, and viva voce stages with separate rules and syllabuses. The current cycle and year-specific FPSC notices control the requirements.

## Preparation

Prepare compulsory and optional written subjects from the official syllabus. Build English essay and précis skills, analytical writing, Pakistan Affairs, Current Affairs, General Science & Ability, and the selected optional subjects. Use MCQs only as supplementary revision, not as a substitute for descriptive answer writing.
