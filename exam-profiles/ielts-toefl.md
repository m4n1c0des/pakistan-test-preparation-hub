# IELTS and TOEFL iBT

**Authority:** IELTS / ETS  
**Official reference:** https://ielts.org/take-a-test/test-types/ielts-academic-test  
**Checked:** 2026-11-24

## Pattern note
Both assess English proficiency across skills, but task types, timing, scoring, delivery, and versions differ. IELTS Academic and General Training are not interchangeable. TOEFL iBT changed its task structure in 2026; use the current ETS page.

## Areas to prepare
Listening, reading, writing, and speaking; practise the exact test version you intend to take.

## Candidate checklist
- [ ] Confirm latest advertisement/notice and test date.
- [ ] Confirm eligibility and test category.
- [ ] Download current official syllabus/sample paper, if available.
- [ ] Confirm duration, question types, negative marking, and calculator rules.
- [ ] Build a timed practice plan only after confirming the above.
