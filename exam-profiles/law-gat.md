# Law Graduate Assessment Test (LAW-GAT)

**Authority:** HEC Education Testing Council (ETC)  
**Official ETC portal:** https://etc.hec.gov.pk/  
**ETC announcements/results:** https://www.hec.gov.pk/english/services/students/etc/Pages/Announcements.aspx  
**Checked:** 2026-11-24

LAW-GAT is a separate assessment for law graduates and should not be confused with LAT, which is for admission to an LLB programme. Use the current HEC/ETC advertisement, eligibility rules, syllabus, and test instructions. This repository does not yet contain a dedicated LAW-GAT subject bank.
