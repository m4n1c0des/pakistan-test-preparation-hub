# Technical hiring assessments

**Authority:** Employer/platform specific  
**Official reference:** https://support.hackerrank.com/articles/2354192461-question-types-in-hackerrank-tests  
**Checked:** 2026-11-24

## Pattern note
There is no universal technical hiring format. Platforms and employers may combine coding, MCQs, SQL, debugging, front-end, data science, system design, or written tasks. Read the job-specific instructions.

## Areas to prepare
Problem solving, coding, data structures, algorithms, SQL, web/mobile, testing, cloud, and role-specific skills.

## Candidate checklist
- [ ] Confirm latest advertisement/notice and test date.
- [ ] Confirm eligibility and test category.
- [ ] Download current official syllabus/sample paper, if available.
- [ ] Confirm duration, question types, negative marking, and calculator rules.
- [ ] Build a timed practice plan only after confirming the above.

> This profile is an orientation note, not an official notice or a promise of exact paper composition.
