# Question quality review checklist

Use this checklist for every new question before changing its status to `editorially_reviewed`.

- [ ] The question tests a clearly identified syllabus/competency point.
- [ ] The stem is complete, unambiguous, and grammatically clear.
- [ ] Exactly one option is defensibly correct for a single-choice item.
- [ ] Distractors are plausible but not also correct under a reasonable interpretation.
- [ ] Any calculation has been independently recomputed; units and rounding are explicit.
- [ ] The explanation shows the reasoning, not only a restatement of the answer.
- [ ] Difficulty and cognitive level match the actual thinking required.
- [ ] Exam tags indicate topic alignment only, not past-paper provenance.
- [ ] Any adapted material has a source and compatible open licence; otherwise write an original question.
- [ ] A second subject-aware reviewer has checked the answer and explanation.

`automated_checks_passed_pending_human_review` means only that structural checks passed. It does **not** mean a subject expert has verified the item. `editorially_reviewed` should be used only after the content review has actually happened.
