# Version 3.0.0 release notes

## Scope
- 500 original practice single-answer MCQs across 18 subjects.
- 322 new v3 questions in quantitative reasoning, analytical reasoning, computer science, English, biology, chemistry, physics and agriculture.
- Short Roman Urdu learning notes on v3 items.
- Separate original writing, coding, numerical-response, and speaking/listening practice formats.
- A human review queue with two reviewer fields for every new v3 question.

## Review status
All 322 v3 items are marked `automated_checks_passed_pending_human_review`. The 98 v2 items retain the same pending status. Only the original 80 v1 items are labelled `editorially_reviewed`. Automated validation checks data structure and consistency; it cannot prove every answer or explanation is factually correct.

## Known limitations
- No independent subject expert has signed off on the v3 bank.
- Difficulty is editorial, not psychometrically calibrated using pilot responses.
- Mock-test generation samples by tag; it does not reproduce an official paper's exact blueprint or adaptive behavior.
- Roman Urdu notes are short learning aids, not full translations.
- Non-MCQ formats are practice design templates, not scored automated assessments.

## Recommended next steps
1. Assign a subject reviewer and a second reviewer to each v3 question.
2. Record corrections in `docs/v3-human-review-queue.csv`.
3. Change review status only after the checklist is complete.
4. Pilot questions with learners and review item difficulty, discrimination and distractor performance before describing the bank as calibrated.
5. Recheck official exam notices before each new admission/recruitment cycle.
