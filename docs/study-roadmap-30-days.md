# 30-day starter roadmap

This is a flexible practice routine, not an official exam timetable. Adapt it to the syllabus and available study time.

| Days | Focus | Daily output |
|---|---|---|
| 1–3 | Confirm test, syllabus, and baseline | One timed diagnostic; topic gap list |
| 4–8 | Core verbal/English | 20–30 questions + error log |
| 9–13 | Quantitative foundations | 15–25 questions; show calculations |
| 14–18 | Analytical reasoning | 15–25 questions; explain logic |
| 19–23 | Subject-specific syllabus | Targeted notes + practice set |
| 24–26 | Mixed timed practice | Two timed sections |
| 27–28 | Weak-area repair | Reattempt missed questions |
| 29 | Full mock | Simulate the confirmed test conditions |
| 30 | Review and rest | Analyse errors; prepare logistics |

For language tests, replace generic MCQs with practice in all four skills. For coding tests, include timed implementation and debugging.
