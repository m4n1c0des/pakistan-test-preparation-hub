# FAQ

**Are these official past-paper questions?** No. The initial bank contains original practice questions.

**Does one pattern fit every FPSC/PPSC test?** No. The exact post advertisement and syllabus control.

**Are difficulty labels statistically calibrated?** No. They are editorial estimates until pilot data is collected.

**Can I add Urdu questions?** Yes. Preserve the schema and set `language` appropriately; ensure fonts and rendering support Urdu.

**Can I add coding or essay questions?** Yes, but define a separate schema and validator rather than shoehorning them into single-choice MCQs.
