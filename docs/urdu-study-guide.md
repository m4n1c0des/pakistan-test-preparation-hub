# Quick study guide (simple English + Urdu terms)

This guide explains common test-preparation terms. The question bank itself is currently in English.

| Term | Simple meaning | Urdu explanation |
|---|---|---|
| Syllabus | Topics included in a test | امتحان میں شامل موضوعات |
| Exam pattern | Sections, question counts and timing | پیپر کی ترتیب، سوالات اور وقت |
| Verbal reasoning | Understanding words, sentences and arguments | الفاظ اور عبارت کو سمجھ کر جواب دینا |
| Quantitative reasoning | Solving number-based problems | اعداد اور حساب کے سوالات |
| Analytical reasoning | Finding relations, rules and logical conclusions | منطقی تعلق اور نتیجہ اخذ کرنا |
| Difficulty | Estimated challenge of a question | سوال کی اندازاً مشکل سطح |
| Cognitive level | Type of thinking a question requires | سوال میں درکار سوچ کی سطح |
| Mock test | A timed practice paper | وقت کے ساتھ مشقی پیپر |
| Answer explanation | Why an answer is correct | جواب درست ہونے کی وجہ |
| Data leakage | Evaluation information accidentally influencing training | ٹیسٹ ڈیٹا کی معلومات کا ٹریننگ میں شامل ہو جانا |

## Beginner-friendly routine

1. Read one topic summary before attempting questions.
2. Attempt questions without looking at the answer key.
3. Write down why the correct option is right and why your selected option was wrong.
4. Reattempt missed questions after one day and again after one week.
5. Practise with a timer only after you understand the topic.

Do not memorize an exam pattern from an old screenshot. Recheck the official exam page for the current cycle.
